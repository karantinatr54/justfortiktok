Privacy Policy

This application ("Shorts Uploader") automates posting videos that the user owns to the user's own TikTok account.

Data we access

  • Basic profile info (open ID, display name) to identify the account.
  • Video files the user explicitly selects for upload.

Data we store

  • OAuth access and refresh tokens, stored locally on the user's own machine only.

Data sharing

No data is sold or shared with third parties. Videos are sent only to TikTok's official API at the user's explicit request.
